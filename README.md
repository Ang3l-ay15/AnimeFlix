# 🎌 AnimeFlix

A responsive anime-themed website inspired by modern anime streaming platforms. AnimeFlix provides a user-friendly interface for exploring anime titles, browsing genres, and navigating different sections of an anime website.

🔗 **Live Demo:** https://ang3l-ay15.github.io/AnimeFlix/

## 📌 About the Project

AnimeFlix is a front-end web development project designed to showcase an anime browsing experience. It features a modern interface with anime categories, featured titles, genre sections, and navigation inspired by popular streaming platforms.

The project focuses on website layout, responsive design, and user interface development.

## ✨ Features

- **Responsive Design:** Layout adapts to different screen sizes.
- **Navigation Bar:** Links to Home, Browse, Genres, My List, and Sign In.
- **Featured Anime:** Displays anime titles such as Solo Leveling, Demon Slayer, One Piece, and Attack on Titan.
- **Category Filters:** Includes categories such as Action, Fantasy, Adventure, Sports, Completed, and Ongoing.
- **Genre Section:** Organizes anime browsing options by genre.
- **Search Interface:** Includes a search field for anime discovery.
- **My List Section:** Provides a dedicated interface for a personal anime list.
- **Watch Now Buttons:** Includes calls to action on featured anime.
- **Sign-In Interface:** Provides navigation and prompts related to signing in.
- **Email Subscription Interface:** Includes an email input for subscriptions.
- **Loading Screen:** Displays a loading message while entering the anime experience.

> **Note:** These are front-end interface features. Search, account management, subscriptions, watch actions, and other backend-dependent functions are not connected to a backend.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📱 Responsiveness

AnimeFlix is designed to adapt to different screen sizes, including desktop and mobile layouts.

## 🚀 Getting Started

To view the project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.

No backend setup is required to view the front-end interface.
